# Конструктор КП — Первый Бит

Веб-приложение для сборки коммерческих предложений: загружаете JSON со структурой КП, редактируете содержимое в браузере и скачиваете готовую презентацию **PPTX в фирменном стиле «Первый Бит»** (чёрный `#1D1D1B` + маджента `#E70F6F`).

## Возможности

- **Загрузка JSON** со структурой: линии → участки → позиции, общее оборудование, ПО, ограничения, зона ответственности заказчика, сопроводительное письмо, настройки
- **Редактирование**: все разделы, позиции, цены и описания; добавление/удаление линий, участков, позиций
- **НДС**: ставка по умолчанию 22% (редактируется, 0 = без НДС); в таблицах отдельные колонки «Цена без НДС / НДС / Сумма с НДС»
- **ПНР**: фиксированная сумма без НДС
- **Живая сводка бюджета**: итого без НДС → НДС → итого с НДС
- **Экспорт в PPTX**: титул, письмо, сводка бюджета, детализация по линиям, оборудование, ПО, ограничения, ответственность, коммерческие условия — с автоматической разбивкой больших таблиц на слайды

## Быстрый старт (без установки)

Откройте файл **`Конструктор-КП.html`** двойным кликом — это полностью автономная версия, работает в любом браузере без сервера и установки программ.

## Запуск из исходников

Требуется Node.js 20+.

```bash
npm install
npm run dev        # http://localhost:3000
```

Или просто запустите `Запустить-КП-конструктор.bat` (Windows) — он сам найдёт Node.js, поднимет сервер и откроет браузер.

## Сборка

```bash
npm run build                                  # продакшн-сборка в dist/
npx vite build --config vite.single.config.ts  # автономная версия одним HTML-файлом в dist-single/
```

## Формат входного JSON

```json
{
  "lines": [{ "line_name": "Линия 1", "sites": [{ "site_name": "Участок", "items": [
    { "item_name": "Позиция", "description": "Текст", "unit": 1, "unit_price": 100, "total": 100 }
  ]}] }],
  "shared": [], "software": [],
  "limitations": [{ "description": "..." }],
  "customer_responsibilities": [{ "description": "..." }],
  "cover_letter": "Текст письма",
  "settings": [{ "currency": "RUB", "client_name": "ООО «Клиент»",
                 "commissioning": 100000, "shipment_terms": "40 рабочих дней",
                 "vat_rate": 22 }]
}
```

`commissioning` — сумма ПНР без НДС; `vat_rate` — ставка НДС, % (если поля нет, подставляется 22).
